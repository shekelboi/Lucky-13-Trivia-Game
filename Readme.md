# Lucky 13 Trivia Game

Kudos to [opentdb.com](https://opentdb.com/) (PixelTail Games LLC.) for providing the questions found in `db.json`.

## Rules

The player has to answer 13 questions and need to guess the number of questions they answered correctly.

### Lucky Ranges

One of the following ranges can be selected as the number of correct answers:

| Correct Answers | Prize |
| --------------- | ----- |
| 13              | $1M   |
| 10-12           | $100k |
| 7-9             | $25k  |
| 4-6             | $15k  |
| 1-3             | $5k   |

One answer can be changed before selecting the range.

#### Lucky Number

An extra lucky number has to be selected, if the player guesses the number of correct answers precisely, they get an extra $25k.

## Offers

Offers come occasionally, the offered prize is proportional to the probability of winning.
